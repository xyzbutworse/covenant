# Visual system

COVENANT uses the supplied terminal-style reference as **visual direction**, not as a template to clone.

## Preserved qualities

- near-black field;
- dense low-contrast financial/proof data as environmental texture;
- one restrained electric-violet system accent;
- a single centered product statement rather than generic card spam;
- compact bottom navigation;
- high-contrast white display typography;
- monospaced microcopy for chain/proof metadata.

## Deliberately original elements

- COVENANT name and geometric interlocking mark;
- proof-conditioned credit narrative;
- DRAW → PAY THERE → PROVE → UNLOCK HERE interaction grammar;
- facility/covenant operator surfaces;
- proof-state and adversarial-state language;
- violet/green/red semantic system.

## Rules

- No neon gradient fog.
- No glassmorphism dashboard soup.
- No decorative “verified” states that are not backed by real evidence.
- Judge-facing read surfaces must work without a connected wallet.
- Live/deployed states and demo/rehearsal states must be visually distinguishable.
